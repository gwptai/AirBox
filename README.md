# AirBox — автономная iPhone-медиатека

AirBox — standalone iOS-приложение. После установки оно не использует Expo Go, Metro, `npx expo start`, ПК, Wi-Fi или интернет для локальной библиотеки и AI.

## Что работает офлайн

- импорт видео и музыки из приложения «Файлы»;
- копирование каждого импортированного файла в приватное хранилище AirBox;
- библиотека, поиск, избранное, сортировка, переименование и удаление;
- видео, полноэкранный просмотр, музыка, play/pause, перемотка и сохранение прогресса;
- сохранение библиотеки, названий, избранного, истории воспроизведения и истории AI после перезапуска;
- локальный AI-чат с потоковым выводом и остановкой генерации.

## Локальный AI

Используется **Liquid LFM 2.5 350M**, экспортированный в ExecuTorch XNNPACK `8w4da` (квантованный) формат.

- Вес модели: около **265 МБ**; токенизатор: около **4,7 МБ**.
- Движок: **ExecuTorch** внутри native iOS build.
- Ориентир по памяти: примерно **500–800 МБ** при активном чате; зависит от модели iPhone и длины контекста.
- Модель находится в `assets/models/` и упаковывается в IPA. В рантайме не скачивается и не обращается к API.
- AI создаётся только при открытии экрана AI, освобождается при возврате в библиотеку, хранит не более 40 сообщений и в модель передаёт максимум 16 последних.

Минимальная версия iOS для AI: **iOS 17**.

## Сборка для iPhone без Mac

1. Создайте аккаунт на [Expo](https://expo.dev/) и оформите Apple Developer Program.
2. Выполните `npx eas-cli login`.
3. Для тестовой сборки выполните `npx eas-cli build --platform ios --profile preview`.
4. Для TestFlight выполните `npx eas-cli build --platform ios --profile production`, затем `npx eas-cli submit --platform ios`.

## Сборка для Android

Для установочного APK выполните `npx eas-cli build --platform android --profile preview`.

## Проверка автономности

1. Установите полученную standalone-сборку, не Expo Go.
2. Добавьте медиафайлы из «Файлов».
3. Закройте AirBox, выключите ПК и включите авиарежим.
4. Откройте AirBox: библиотека, плееры и AI продолжат работать локально.

## Важно

AirBox предназначен для личных файлов, которыми вы вправе пользоваться. Приложение не загружает и не распространяет фильмы: после добавления файл хранится только на устройстве. Удаление приложения iOS удаляет его приватные файлы и историю — это стандартное поведение iOS.
